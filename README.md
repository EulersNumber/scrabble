# Scrabble scorepad

Family Scrabble **scorekeeping** app (physical board; this app only records scores).

## Setup

```bash
npm install
npm run dev
```

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run dev` | Local Vite dev server |
| `npm run build` | Typecheck + production build |
| `npm test` | Run Vitest once |
| `npm run preview` | Preview production build |

See `docs/` and `AGENTS.md` for product and architecture rules.
